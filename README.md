# Suzuka's Pelican Cover Flag v1.0.0

安装包：`Suzukas-Pelican-Cover-Flag-v1.0.0.zip`
SHA-256：`6A53A61213558E04A79AA79EE758BA879DA7AD46BDD9269343055EF318AA5EB2`

## 功能
- 拿起 CQC-1 唯一真旗后，会呼叫一架鹈鹕运输机前来掩护。它用原版炮塔开火，并跟随持旗者。
- 飞机从玩家附近高空入场，走原版进场流程，之后悬停在持旗者上方约 25 单位处跟随。
- 丢下旗子后，飞机按原版流程撤离。
- 每架飞机最多停留 180 秒。旧飞机离开后若仍持旗，会再派一架；次数不限，同一时间只有一架。
- 只控制本模组呼叫的飞机，不影响玩家自己呼叫的载具投送机和撤离机。
- 主机与客机都会尝试呼叫，未做联机同步验证。

## 安装
1. 需要 Bingus Shared Loader v15 或更新版本（API 1）。
2. 在加载器中添加本 zip 并部署，然后完全重启游戏。

## 说明
- 适配的游戏版本：game.dll SHA-256 `2e2c3b7c…18f51e`。游戏更新后，模组检测到原生代码不符会停止呼叫飞机，需要等待适配。
- 日志：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\SuzukaPelicanCoverFlag.log`，每 5 秒记录一行模组耗时统计。
- 持旗者阵亡时，飞机可能被游戏移除；复活后重新拿起旗子即可再次呼叫。
- 本模组会直接调用游戏原生函数生成和撤离飞机，请自行承担风险。
